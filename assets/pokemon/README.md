# ポケモンアイコン

オフ会結果の使用パーティとKP一覧に表示する、BW世代の32×32pxのメニューアイコンです。
現在のサンプルデータに登場する38種を同梱しています。ページ表示時に外部APIへの通信は行いません。

- 配布元：[PokéAPI / sprites](https://github.com/PokeAPI/sprites)
- 取得元コミット：`c0542f7c51215d9672439012838c99f520596cbd`
- 取得元ディレクトリ：`sprites/pokemon/versions/generation-v/icons/`
- ファイル名：全国図鑑番号（例：`143.png`＝カビゴン）
- 日本語の種族名と図鑑番号の対応：`assets/data.js` の `pokemonIds`

画像は配布元のPNGを加工せず保存しています。Pokémonの画像・キャラクターの権利は各権利者に帰属します。

表示する種族を追加する際は、`pokemonIds` に種族名と全国図鑑番号を追加し、対応するPNGをこのディレクトリに配置してください。
対応する図鑑番号が未登録の場合も、画面には種族名を表示します。
